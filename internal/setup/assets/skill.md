name: rdxt
description: Open, show or create Markdown (.md) and Dok (.dok) documents for the user with rdxt, in Rex. Use after writing or substantially updating a Markdown or Dok file the user should read (a plan, report, design doc, README, notes), or when the user asks to open, show, preview, read or create a document.

Run `rdxt agent-guide` and follow the guide it prints. The guide comes from
the installed rdxt, so it matches that version.

If the command fails, rdxt isn't available: mention the file's absolute path
and continue.
